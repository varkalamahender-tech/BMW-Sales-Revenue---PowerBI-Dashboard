## 🎯 Project Objective

The objective of this project is to build an interactive sales analytics dashboard using Power BI and explore BMW sales data across different models, regions, and years.

The dashboard provides a simple way to analyze:

- Total cars sold
- Calculated revenue
- Revenue by BMW model
- Revenue by region
- Sales volume by BMW model
- Year-based filtering
- Model-based filtering
- Region-based filtering
